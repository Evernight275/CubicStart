# internal 包的强制约束

以下规则适用于本目录及所有子目录，是用户明确强调的重要项目约定。

- 每个 Go 包的唯一对外入口必须统一命名为 `interface.go`，新增包同样适用。
- 导出的接口、数据类型、函数、变量、常量，以及导出类型的公开方法，必须声明在该包的 `interface.go` 中。
- 其他 Go 文件只负责内部实现，具体实现类型必须保持不导出；未导出类型为满足接口而定义的公开方法，可以放在实现文件中。
- 跨包调用只使用对方 `interface.go` 中定义的公开契约，不额外建立其他公开入口。
- Go 的导入单位仍然是包；本规则约束公开声明的位置，不使用单文件导入来描述实现方式。
- 不得为方便实现而改名入口、将公开声明移至其他文件，或放宽根目录 `architecture_test.go` 中的检查。调整这项约定必须有用户明确指示。
- 修改 Go 代码后运行 `go test ./...`，确保入口约束检查通过。

各包职责及依赖方向见本目录的 `README.md`。
